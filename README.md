<section>
    <h2>Warum begann die Revolution?</h2>

    <ul>
        <li>Frankreich war keine Demokratie.</li>
        <li>Der König hatte sehr viel Macht.</li>
        <li>Der Dritte Stand hatte kaum Mitspracherecht.</li>
        <li>Viele Menschen lebten in Armut.</li>
        <li>Schlechte Ernten machten Brot sehr teuer.</li>
        <li>Adel und Klerus hatten viele Privilegien.</li>
    </ul>
</section>

<section>

    <h2>Die drei Stände</h2>

        <li><strong>2. Stand:</strong> Adel</li>
        <li><strong>3. Stand:</strong> Bauern, Handwerker und Bürger</li>
    </ul>

    </p>
